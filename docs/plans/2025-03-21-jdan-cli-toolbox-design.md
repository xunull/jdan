# jdan：Go 多工具 CLI（设计）

**状态：** 已定稿（2025-03-21）  
**范围：** 单二进制、按领域分组的子命令；首条能力为「文件备份到同目录、带 `.bak` 与时间戳」。

## 目标

提供一个可扩展的 **常用命令集合**，以 **一个二进制** 发布。首个子命令实现：将指定文件复制到同目录下的备份文件，文件名在原完整文件名（含扩展名）基础上追加 **`.bak`、本地时间戳**，并可附加 **可选描述**。

## 架构

- **形态：** 单二进制 + **按领域分组**（例：`jdan file bak <path>`）。后续同类能力挂在 `file` 下，其它领域另起顶层分组。
- **技术栈：** **Cobra**（根命令与子命令）、**Viper**（配置；优先级：命令行 > 环境变量 > 配置文件 > 默认，见项目技能文档）、**zerolog**（`ConsoleWriter` 输出人类可读文本）。
- **目录（示意）：**
  - `cmd/jdan/main.go`：初始化 `zerolog` 全局 `log.Logger`，调用 `Execute()`。
  - `internal/cli/`：Cobra 根命令与 `file bak` 注册。
  - `internal/filebak/`（或等价包名）：备份目标路径计算、描述校验与规范化、复制逻辑（便于单测与复用）。

## `file bak` 功能规格

### 参数

- **必填：** 源文件路径（相对或绝对均可）。
- **可选：** `--desc`（字符串）；不提供或规范化后视为「无描述」时，备份名不含 `-{desc}` 段。

### 备份路径与命名

- **目录：** 与源文件相同（`filepath.Dir` / 等价逻辑）。
- **时间戳：** 本地时区，格式 **`YYYYMMDD-HHMMSS`**，与 `20060102-150405` 一致，示例：`20250321-153045`。
- **无描述：** `{basename}.bak.{timestamp}`  
  例：`report.pdf` → `report.pdf.bak.20250321-153045`
- **有描述：** `{basename}.bak.{timestamp}-{descNormalized}`  
  例：`report.pdf` → `report.pdf.bak.20250321-153045-before_edit`

### 描述处理与字符约束

1. **`strings.TrimSpace`**。若结果为空 → **视为未提供描述**（与完全不传 `--desc` 相同，**不**在文件名末尾多留 `-`）。
2. **合法性校验（在替换空格之前，对 trim 后的字符串逐码点检查）：**  
   仅允许：
   - 英文字母：`a-z`、`A-Z`
   - 数字：ASCII `0-9`
   - 汉字：Unicode **Han** 码位（实现使用 `unicode.Is(unicode.Han, r)` 或等价方式）
   - 空格：ASCII 空格 `U+0020`（用于后续转为下划线）
3. **若出现任何其它字符**（含各类标点、制表符、换行、其它符号等）：  
   - **打一条日志提示用户**（zerolog，级别可用 `Warn` 或 `Error`，文案说明「描述仅允许英文字母、汉字、数字与空格」）。  
   - **立即退出，非零状态码，不进行任何复制。**
4. **通过校验后：** 将字符串中的 **空格** 全部替换为 **`_`**，得到 `descNormalized`，再拼入文件名。

### 冲突与错误

- 源不存在、或不是**普通文件**：报错退出，不创建备份。
- 计算出的目标路径**已存在**：**不复制**；日志/错误信息明确提示 **已存在相同时间戳的备份**（或等价清晰中文），**非零退出**。
- 复制过程失败（权限、磁盘满等）：返回/记录错误，**非零退出**。

### 配置（Viper）

首版以 flag + 默认值为主；仍按 `.cursor/skills/go-cli-cobra-viper/SKILL.md` 预留 Viper 绑定顺序，便于后续增加全局选项（如日志级别、配置文件路径等）。

## 测试策略

- **单元测试：** 描述 trim/空描述、合法字符校验（含标点应失败）、空格→下划线、完整目标文件名生成。
- **建议：** 临时目录下的集成测试，覆盖成功复制与「目标已存在」分支。

## 非目标（YAGNI）

- 不自动递增序号覆盖重名。
- 不改变备份目录（固定为源文件同目录）。
- 首版不要求配置文件驱动该子命令行为（除全局 CLI 基础设施外）。
