# jdan lunar

公历 ↔ 农历（中国阴历）转换，含**干支纪年、生肖、农历节日**。内嵌 1900–2100 农历表（公开算法、~200 个常量），**0 新依赖**。

## 它能干什么

```bash
$ jdan lunar
公历: 2026-06-26 (周五)
农历: 丙午年 五月十二  (生肖 马)

$ jdan lunar 2024-02-10              # 指定公历日 → 农历
公历: 2024-02-10 (周六)
农历: 甲辰年 正月初一  (生肖 龙)

$ jdan lunar --to-solar 2026 1 1     # 农历 → 公历（今年春节几号）
农历: 丙午年 正月初一
公历: 2026-02-17 (周二)

$ jdan lunar --to-solar 2025 6 1 --leap   # 闰月（2025 闰六月初一）
$ jdan lunar 2026 --festivals        # 列某年农历节日
$ jdan lunar 2026-06-26 --json
```

## 子命令 / flags

| 形式 | 含义 |
|------|------|
| `jdan lunar [YYYY-MM-DD]` | 公历 → 农历（默认今天） |
| `jdan lunar --to-solar <年> <月> <日> [--leap]` | 农历 → 公历 |
| `jdan lunar [year] --festivals` | 列某公历年的农历节日（默认今年） |
| `--json` | 结构化输出 |

农历节日（纯农历日期推出）：春节、元宵、端午、七夕、中秋、重阳、除夕。清明/冬至属**节气**（太阳历），不在此列。

## 正确性怎么守护（这是命门）

农历转换极易出微妙 bug（闰月、边界日、春节锚点），所以用两道防线：

1. **真实锚点**：2024/2025/2026 春节、中秋、端午、闰月（2025 闰六月 / 2023 闰二月 / 2020 闰四月）逐一断言公历↔农历。
2. **全程 round-trip**：1900–2100 每 ~29 天采样，`公历 → 农历 → 公历` 必须回到原值。表或算法任一处错位都会被它逮住。

范围 1900–2100，越界报清晰错误（注意：如 2101-01-01 公历仍属农历 2100 年腊月，不算越界）。

## 算法 & 0 依赖

`lunarInfo[year-1900]` 每年一个整数编码：

- bits 4–15：1..12 月大小（1=30 天，0=29 天）
- bits 0–3：闰月号（0=无闰月）
- bit 16：闰月是否 30 天

加上锚点 `1900-01-31 = 农历 1900 正月初一`，公历↔农历就是「按年/月累减或累加天数」的纯算术。这是 HTML5/Python `lunardate` 等众多实现用的同一套公开表，**不引第三方库**。

干支：天干 `(年-4)%10`、地支 `(年-4)%12`；生肖取地支。**以正月初一为界**（生肖年）。注：传统干支历以立春为界，本实现取春节边界（更贴近大众「生肖年」直觉），立春边界待 `--solar-terms`。

## 内部架构 & 可测性

```
internal/lunarx/lunarx.go
  SolarToLunar(t) (Lunar, error)              —— 公历 → 农历
  LunarToSolar(year, month, day, leap) (time.Time, error)  —— 农历 → 公历
  Festivals(solarYear) []Festival             —— 农历节日（按公历日期排序）
  GanzhiYear / Zodiac / MonthName / DayName   —— 名称与干支
internal/cli/lunar.go                          —— 解析 + 模式分发
```

CLI 注入 `now time.Time`，「今天」可复现测试；转换逻辑完全不依赖时钟。

|------|-----------|
| 成功 | 0 |
| 非法日期 / 越界 / 无该闰月 | 1 |

## 有意不做

| 候选 | 原因 |
|------|------|
| 黄历宜忌 / 吉时 | 无统一权威算法，做了等于编 |
| 24 节气 | 属太阳历，另一套（寿星公式）+ 独立验证，待 `--solar-terms` |
| 月/日干支 | 月干支需节气定界；待节气功能一起做 |
| 第三方农历库 | 内嵌表足矣，守住 0 新依赖 |
| 1900 前 / 2100 后 | 表不覆盖，越界报错 |
| 塞进 `jdan cal` | 叠加破坏对齐；先独立命令 |

## TL;DR

1. `jdan lunar` 今天农历；`lunar 2024-02-10` 指定日；`--to-solar 2026 1 1` 反查春节
2. 干支纪年 + 生肖 + 闰月标注 + 农历节日（春节/元宵/端午/七夕/中秋/重阳/除夕）
3. **正确性靠真实锚点 + 1900–2100 全程 round-trip 双重守护**
4. 内嵌表 + 纯算术，**0 新依赖**；范围 1900–2100
5. 不做黄历宜忌/节气（无权威算法/属太阳历），跟 `cal` 互补
