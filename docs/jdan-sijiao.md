# jdan sijiao — 四角号码查询（字→码，离线，0 新依赖）

查汉字的**四角号码**（王云五检字法）。只做正查（字→码），反查（码→字）暂不支持。
数据是 [Unicode Unihan](https://www.unicode.org/charts/unihan.html) 的 `kFourCornerCode` 字段，
生成 Go 表二分查找，**0 新依赖** —— 跟 `strokes` 同源同架构（同一份 Unihan、同一套 gen + 排序表 + 二分）。

## 原理

四角号码看一个字**四个角的笔形**（左上、右上、左下、右下），每角按 10 类笔形取一位 → 4 位主码，
右下角上方的笔形再取一位作**附号**消歧 → `NNNN.N`（无附号则 `NNNN`）。

十类笔形口诀：
```
横一 垂二 三点捺 叉四 插五 方框六 七角 八八 九是小 点下有横变零头
1横(一) 2垂(丨) 3点捺(丶) 4叉(十) 5插(中丰) 6方框(口) 7角(コ折) 8八(八人) 9小(忄) 0亠(讠)
```
`口` = 左上方框6，其余三角空0 → `6000`，附号0 → `6000.0`。

**只能查表，不能算**：四个角的笔形要看字形，从码点算不出来（和笔顺一个道理——没有开放的字形/笔形机读数据）。
表就是 Unihan `kFourCornerCode`，和 `strokes` 的 `kTotalStrokes` 一个模子。

## 用法

```bash
$ jdan sijiao 王              # 王  1010.4
$ jdan sijiao 你              # 你  2729.0, 2729.2   （多值，同字用逗号）
$ jdan sijiao 口业专          # 口 6000.0 / 业 3210 / 专 5030   （字与字用斜杠）
$ echo 王 | jdan sijiao        # 从 stdin 读
$ jdan sijiao --json 你口
```

非汉字（字母/数字/标点/emoji）跳过不计。是汉字但表里查不到的标「无 / ?」，末尾提示「另有 N 字无四角号码」。

## 能力边界（诚实划界）

- **只给码，不做逐角分解**：Unihan 只存最终的四角码，不存"左上=口→6"的分解。`--help` 内置口诀教方法，但不逐字拆角。
- **覆盖约 1.69 万字**（16,916 常用/传统字）。深扩展区生僻字没有四角码 —— 这是四角号码本身的范围，不是缺陷，但表外汉字会标「无」。
- **只做正查（字→码）**：反查（码→字，查旧字典的核心用法）本版不做，留作后续增量。
- 四角号码是前拼音时代的老检字法，受众小。此命令的价值是"离线、补检字线（和 strokes 同源）"，不是消日常痛点。

## 实现要点

- `//go:generate` 从 `kFourCornerCode` 生成 `sijiao_dict.go`（`sijiaoCP []rune` 升序 + `sijiaoCode []string` 平行），二分查找。
- **多值整串保留**：149 个字有 2 个码（如 `你`→`2729.0 2729.2`），gen 工具**不截断**（与 `gen_strokes` 的"只取第一个"相反，照抄会吃掉第二码）。运行时 `strings.Fields` 拆开。
- 数据实测（Unihan 17.0.0）：16,916 字 / 17,065 码值，带附号 14,894、无附号 2,171；`口→6000.0`、`王→1010.4`、`你→2729.0 2729.2`、`专→5030`。
- 查表顺序同 strokesx：先查表、查不到再 `unicode.Is(unicode.Han,r)` 分未知/跳过（本表稀，这个顺序更要守）。
- 数据源 Unicode，公开可嵌；生成 Go 表进仓库，不嵌原始文件。刷新：重跑 `_tools/gen_sijiao.go`。
